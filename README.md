# AutoDocs

AutoDocs – программное обеспечение для автоматизированного формирования и проверки актуальности документации REST API приложений, разработанных на платформе ASP.NET Core с использованием контроллеров.

Анализ исходного кода выполняется статически с использованием Roslyn, без запуска анализируемого приложения.

## Основные возможности

- Анализ контроллеров, HTTP-методов и маршрутов.
- Определение параметров запросов и типов ответов.
- Извлечение XML-комментариев из исходного кода.
- Генерация документации в форматах OpenAPI 3.0 (JSON) и Markdown.
- Сравнение существующей документации с исходным кодом.
- Классификация обнаруженных расхождений по уровню значимости.
- Обнаружение дублирующихся ключей эндпоинтов.
- Сохранение истории проверок и снимков API в SQLite.
- Работа через командную строку и графический интерфейс.
- Интеграция с GitHub Actions.

## Используемые технологии

- C# и .NET 10

## Системные требования

- .NET SDK 10.0.
- Windows для использования графического интерфейса WPF.
- Git для получения исходного кода.

## Сборка

```bash
git clone https://github.com/Rais1one/autodocs.git
cd autodocs
dotnet restore
dotnet build --configuration Release
```

## Использование CLI

### Генерация документации

```bash
dotnet run --project src/AutoDocs.Cli -- generate --project samples/DemoApi/DemoApi.csproj
```

По умолчанию документация сохраняется в каталоге `docs` анализируемого проекта:

- `openapi.json` – спецификация OpenAPI;
- `API.md` – документация в формате Markdown.

### Проверка актуальности

```bash
dotnet run --project src/AutoDocs.Cli -- check --project samples/DemoApi/DemoApi.csproj
```

### Проверка без сохранения истории

```bash
dotnet run --project src/AutoDocs.Cli -- check --project samples/DemoApi/DemoApi.csproj --no-history
```

### Коды завершения

| Код | Значение |
|---|---|
| 0 | Документация актуальна |
| 1 | Обнаружены расхождения |
| 2 | Ошибка выполнения |

## Графический интерфейс

Запуск приложения:

```bash
dotnet run --project src/AutoDocs.Desktop
```

Графический интерфейс позволяет выбирать анализируемый проект, настраивать генерацию документации, выполнять проверку актуальности, просматривать и фильтровать расхождения, открывать исходные файлы и изучать историю проверок.

## Хранение данных

История проверок и снимки API сохраняются в локальной базе данных SQLite.

Расположение базы данных в Windows:

```text
%LOCALAPPDATA%\AutoDocs\history.db
```

База данных создаётся автоматически.

## Тестирование

```bash
dotnet test --configuration Release
```

В проекте реализовано 62 автоматизированных теста.

## Непрерывная интеграция

GitHub Actions обеспечивает автоматическое восстановление зависимостей, сборку решения, запуск тестов и проверку актуальности документации демонстрационного проекта.

При обнаружении расхождений проверка CI завершается с ошибкой.

## Ограничения

- Поддерживаются приложения ASP.NET Core на основе контроллеров.
- Minimal API не поддерживается.
- За один запуск анализируется один проект.
- Проверка актуальности выполняется относительно документации OpenAPI в формате JSON.
- Динамически формируемые маршруты и поведение приложения во время выполнения не анализируются.
- Исходный код анализируемого проекта автоматически не изменяется.
- Следует анализировать только доверенные проекты.
