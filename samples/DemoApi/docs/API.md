# DemoApi

Версия API: v1

## GET \/api\/Orders

Получить заказы клиента.

### Параметры

clientId: string; Источник: Header; Обязательный: Да; Описание: Идентификатор клиентского приложения из заголовка.

userId: int?; Источник: Query; Обязательный: Нет; Описание: Фильтр по пользователю; если не задан, возвращаются все заказы.

### Ответы

Список заказов.

200: IEnumerable\<OrderDto\>

## POST \/api\/Orders

Создать заказ.

### Параметры

request: CreateOrderRequest; Источник: Body; Обязательный: Да; Описание: Данные заказа.

### Ответы

Созданный заказ.

201: OrderDto

## GET \/api\/Orders\/{id}

Получить заказ по идентификатору.

### Параметры

id: int; Источник: Route; Обязательный: Да; Описание: Идентификатор заказа.

### Ответы

Найденный заказ.

200: OrderDto

404: Без тела ответа

## GET \/api\/Users

список пользователей с постраничным выводом.

### Параметры

page: int; Источник: Query; Обязательный: Нет; Описание: Номер страницы, начиная с 1.

pageSize: int; Источник: Query; Обязательный: Нет; Описание: Количество записей на странице.

### Ответы

Список пользователей.

200: IEnumerable\<UserDto\>

## POST \/api\/Users

Создать нового пользователя.

### Параметры

request: CreateUserRequest; Источник: Body; Обязательный: Да; Описание: Данные нового пользователя.

### Ответы

Созданный пользователь.

201: UserDto

400: Без тела ответа

Получить пользователя по идентификатору.

### Параметры

id: int; Источник: Route; Обязательный: Да; Описание: Идентификатор пользователя.

### Ответы

Найденный пользователь.

200: UserDto

404: Без тела ответа

## PUT \/api\/Users\/{id}

Обновить данные пользователя.

### Параметры

id: int; Источник: Route; Обязательный: Да; Описание: Идентификатор пользователя.

request: UpdateUserRequest; Источник: Body; Обязательный: Да; Описание: Новые данные пользователя.

### Ответы

204: Без тела ответа

404: Без тела ответа
